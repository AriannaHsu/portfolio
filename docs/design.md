# Design tokens — Minimal ink, warm base

## Colors

| Token | Hex | Use |
|---|---|---|
| `bg-base` | `#F4F1EC` | Page background (warm off-white) |
| `bg-surface` | `#F9F6F0` | Card / section background |
| `border` | `#E3DFD5` | Hairline dividers between cards/sections (no borders/shadows) |
| `text-primary` | `#2C2A28` | Headlines, primary text (warm charcoal, near-black) |
| `text-secondary` | `#8A857D` | Body copy, nav, secondary/system text (warm gray) |
| `accent` | `#C9B8E8` | Accent — underlines, small highlights only (soft lavender). Never a large color block. |
| `accent-hover` / `accent-text` | `#5A4E85` | Accent link text and hover states (deeper lavender-plum) |

**Texture:** very subtle background grain — barely-there, not a visible paper/fabric weave.

## Typography

| Role | Font | Notes |
|---|---|---|
| Headers | Perfectly Nineties | Fallback: Georgia |
| Body copy | Suisse | |
| System text (nav, footer, hover states) | Nimbus | |

**Scale note:** homepage hero headline should be large and confident (~42px desktop) — this scale carries the editorial feel, don't shrink it to fit more above the fold.

## CTA style
Understated text link with colored underline (e.g. "Download resume →"), not a heavy filled button.

## Layout principle
Personality comes from interaction (hero visual, footer moment, guided nav), not from a busier color palette. Keep the base quiet; let motion carry the warmth.
